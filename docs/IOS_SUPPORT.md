# 喵撲 Meowpuut · 使用說明

米米莫和莫莫陪你打字。

## 加入鍵盤

安裝喵撲後，打開 iPhone 或 iPad 的「設定 → 一般 → 鍵盤 → 鍵盤 → 加入新鍵盤」，選擇 Meowpuut。回到文字框，長按地球鍵即可切換。

不需要開啟「允許完整取用」。中文轉換與選詞都在裝置上完成。

## 選擇輸入方式

在喵撲 App 右上角打開「鍵盤設定」，選擇拼音或注音，以及繁體或簡體。回到鍵盤後會套用設定。外觀、配色、玻璃強度也在同一頁調整。

- 拼音：輸入 `nihao`，點選「你好」。長句可以先選前半段，再繼續選剩餘部分。
- 注音：使用大千排列，空格輸入一聲；想保留注音符號時，點候選列上的「ㄅㄆ」。
- 中日混打：在拼音中輸入 `wosukini`，可選「我好き你」。帶小貓爪的候選含日語。
- 長按刪除可以連續刪字；長按空格後左右滑動可以移動游標。
- 點候選列右側的箭頭展開更多候選，向左右滑動可查看其他頁。

## 個人用詞

常用詞可以隨選詞習慣在裝置上累積。在「鍵盤設定」可關閉記憶或清除個人用詞；清除會在下次打開鍵盤時執行。

## 沒有看到鍵盤？

先確認已在系統設定加入 Meowpuut，再長按地球鍵選擇。密碼等安全輸入欄，以及部分不允許第三方鍵盤的 App，會使用系統鍵盤。
